# Правила проекта

## Python

Используем Python 3.12. Пишем код с учётом возможностей этой версии и запускаем тесты на Python 3.12.

## Docstrings

Пишем на русском, в стиле Google.

## TDD

Тесты пишем только для Python.

Используем TDD: сначала пишем падающий тест, затем реализацию, после — рефакторинг.

Тесты должны проверять значимое поведение и защищать от регрессий. Не добавляем тесты ради покрытия.
