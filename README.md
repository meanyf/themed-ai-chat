# Тематический AI-чат

Одностраничный чат с языковой моделью. Тема задаётся системным промптом.

## Запуск

Понадобятся Git, Docker с Compose и ключ Gemini API. Ключ можно получить на <https://aistudio.google.com/api-keys>.

### Linux и macOS

```bash
git clone https://github.com/meanyf/themed-ai-chat.git
cd themed-ai-chat
cp .env.example .env
```

### Windows (PowerShell)

Запустите Docker Desktop и выполните в PowerShell следующие команды.

```powershell
git clone https://github.com/meanyf/themed-ai-chat.git
cd themed-ai-chat
Copy-Item .env.example .env
```

В скопированном `.env` укажите свой ключ в `GEMINI_API_KEY`, затем запустите проект.

```bash
docker compose up --build -d
```

Контейнер приложения дождётся готовности PostgreSQL, применит миграции Alembic и запустит FastAPI.

Откройте <http://localhost:8000> и введите `ACCESS_KEY` из `.env` (в примере — `local_chat_key`).

Остановить проект можно командой `docker compose down`. История сохраняется в томе `postgres_data`.

## Устройство проекта

Бэкенд следует принципам **чистой архитектуры**. Зависимости направлены внутрь: слой сценариев использует доменные сущности и определяет интерфейсы для работы с хранилищем и моделью. Домен и сценарии независимы от FastAPI, PostgreSQL и Gemini.

Например, `ChatService` принимает зависимости через интерфейсы `MessageRepository` и `LLMClient`. Через них он сохраняет вопрос и получает ответ модели. Реализации можно заменить без изменений в сервисе.

PostgreSQL хранит общую историю и сессии между перезапусками. Alembic применяет изменения схемы по версиям. Для одной страницы достаточно HTML, CSS и JavaScript без отдельной сборки. В Docker Compose описаны сервисы приложения и базы, их сеть и зависимость запуска приложения от готовности PostgreSQL. `uv.lock` фиксирует версии Python-зависимостей для повторных сборок.

| Где | За что отвечает |
| --- | --- |
| `app/domain/` | Сущности сообщения и сессии. Здесь проверяются правила, в том числе предел в 500 символов для вопроса. |
| `app/services/` | Сценарии чата и авторизации. |
| `app/services/interfaces/` | Интерфейсы (`Protocol`) репозиториев сообщений и сессий и клиента языковой модели. Сервисы используют эти интерфейсы, а в тестах можно подставить другие реализации. |
| `app/repositories/`, `app/db/`, `migrations/` | Хранение истории и сессий в PostgreSQL через SQLAlchemy, схема таблиц и миграции Alembic. |
| `app/integrations/gemini.py` | Запрос к Gemini с текущим вопросом и системным промптом. |
| `app/api/`, `app/main.py`, `app/core/config.py` | HTTP-маршруты и схемы, сборка приложения и чтение настроек. FastAPI отдаёт страницу и API с одного адреса. |
| `frontend/` | Интерфейс на HTML, CSS и JavaScript. Браузер загружает историю, отправляет вопросы и показывает состояние запроса. |

Вопрос сохраняется **до обращения к Gemini**. Если модель недоступна, вопрос остаётся в истории. При обрыве соединения интерфейс предлагает сверить ленту с сервером перед повторной отправкой.

Тема по умолчанию — кулинария. Чтобы изменить поведение модели, добавьте `SYSTEM_PROMPT="Ваша инструкция для модели"` в `.env` и повторите `docker compose up -d`.

### Авторизация

Для чата с общим ключом используется **сессионная аутентификация**. Она позволяет передать ключ один раз при входе и сразу отозвать доступ текущей сессии при выходе.

Браузер передаёт введённый ключ в теле `POST /api/auth/login`. Сервер сравнивает его с `ACCESS_KEY` и при успехе выдаёт случайный токен в cookie с атрибутами `HttpOnly` и `SameSite=Strict`. Браузер отправляет cookie при обращении к API. В PostgreSQL хранятся SHA-256-хеш токена и срок действия сессии — 24 часа с момента входа. При выходе сервер удаляет сессию и очищает cookie. Ключ Gemini используется только на сервере.

## Что можно доработать

- Добавить идентификатор запроса для каждого вопроса. Тогда после обрыва связи сервер сможет распознать повторную отправку даже при двух одинаковых текстах подряд.
- Загружать старые сообщения порциями при прокрутке вверх, чтобы большой диалог быстро открывался.
- Добавить ограничение частоты попыток входа по ключу доступа.
